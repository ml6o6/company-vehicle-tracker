# Сервис учета автомобилей организации

## Назначение
Консольное приложение для учета автопарка и планирования служебных поездок. 

## Предметная область и основные сущности

- **Автомобиль:** модель, госномер, число пассажирских мест без водителя, текущий пробег, расход топлива, пробег последнего ТО и межсервисный интервал.
- **Водитель:** ФИО и наличие допуска к автомобилям организации. На этапе ПР2 используется общий допуск ко всему автопарку без отдельных категорий прав.
- **Поездка:** автомобиль, водитель, дата, длина полного маршрута и число пассажиров.
- **Обслуживание:** на ПР2 представлено пробегом последнего ТО и интервалом в записи автомобиля; отдельный журнал обслуживания будет добавлен при дальнейшем развитии.

## Возможности ПР2

- Просмотр и добавление автомобилей и водителей.
- Поиск автомобиля по подстроке модели или госномера без учета регистра.
- Проверка, отбор и сортировка автомобилей по пассажирской вместимости.
- Проверка занятости автомобиля и водителя на заданную дату.
- Создание и отмена поездок, просмотр списка поездок с участниками и расчетом топлива.
- Проверка допуска водителя, срока ТО и суммарного запланированного пробега.
- Автоматическая загрузка JSON при запуске и сохранение после каждого изменения.
- Повтор ввода при неверном числе или дате; обработка неизвестных ID и ошибок файлов.

## Структура проекта

- main.py — точка запуска и меню;
- fleet.py — автомобили, водители и контроль ТО;
- trips.py — проверка, создание и отмена поездок;
- storage.py — сохранение и загрузка данных;
- utils.py — вспомогательные функции;
- data/ — JSON-файлы данных;
- tests/ — автоматизированные тесты.

## Требования

- Python 3.10 или новее;
- pytest;
- flake8.
